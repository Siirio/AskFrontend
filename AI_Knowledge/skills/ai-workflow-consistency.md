# AI Workflow Consistency Skill

Use to keep multiple developers and AI agents aligned without enforcing a rigid personal style.

Check whether work:

- matches Ask vision;
- confuses prototype behavior with product architecture;
- invents unavailable facts;
- hardcodes one city, category, supplier, file, frontend, or provider;
- creates frontend/backend contract drift;
- needs documentation updates;
- needs system analysis before code.

If there is a conflict, state it, explain the risk, and offer a compatible path.
