# Architecture System Analysis Skill

Use before coding unclear or risky Ask work.

Trigger for:

- catalog UX;
- services UX;
- schedules shown in UI;
- integration-backed display;
- scaling across cities/countries;
- auth and roles;
- API contract shape;
- client state ownership;
- frontend/backend responsibility split.

Output:

```text
Problem:
Actors:
Current evidence:
Proposed model:
MVP shortcut:
Deferred decisions:
Risks:
Verification:
```

If the analysis exposes a product decision that is not approved, stop and ask before implementation.
